# 靈感城市與點子筆記

[進入靈感城市](https://ioksengtan.github.io/ioksengtan/idea/ideas.html)

城市程式、點子 Markdown 與參考圖片集中於本儲存庫。每個點子是一位居民，住在以點子造型作為屋頂地標的公寓中。

更新快照：在個人站根目錄執行 `node idea/scripts/build-ideas.cjs`。測試：安裝 Playwright 後執行 `node tests/city.test.cjs`（預設 Edge）。

此資料夾由原 `ioksengtan/idea` 倉庫併入個人站（保留提交歷史）。城市開啟時會同步本儲存庫 `idea/` 的最新筆記，無法連線時使用 data/ideas.js 快照。
