## 使用方式

火藥庫收錄看到就想存起來的工具，等哪個點子需要時再來翻。新工具在總覽表加一列、在工具卡補一張，編號接續往下。

- **類別**：語音、Agent 基礎建設、資料取得、文件編輯、影片生成，之後可自行增加。
- **狀態**：未試 → 試過 → 在用，試完記得改。
- **授權**：先看這欄再決定能不能包進對外服務，AGPL 特別留意。

## 工具卡

### #1 VoiceStudio（debpalash）

開源、完全本機運行的語音 AI 桌面應用，前身叫 OmniVoice Studio。提供相容 OpenAI 的本機 API，也有 MCP server。

- 注意：AGPL-3.0，若包成網路服務，修改部分要開源。
- 來源：[everydev](https://www.everydev.ai/tools/voicestudio/llms.txt)

### #2 Hindsight（vectorize-io）

Agent 記憶系統，重點是「學習」而非只存對話。分成世界事實、經驗、觀察等記憶網路，agent 可反思經驗、避免重複犯錯。核心操作是 Retain、Recall、Reflect。

- 注意：LongMemEval 91.4% 是廠商自報數字。
- 來源：[vectorize.io](https://vectorize.io/hindsight)

### #3 Paperclip

Node.js 伺服器加 React UI，把一群 AI agent 組織成公司：組織圖、預算、目標、治理與稽核紀錄。它不取代 Claude Code 或 OpenClaw，而是管理它們。

- 安裝：`npx paperclipai onboard --yes`
- 注意：「零人類公司」偏行銷，實用價值在多 agent 的成本與任務管理。
- 來源：[jimmysong.io](https://jimmysong.io/ai/paperclip)

### #4 Agent-Reach

Python CLI，讓 agent 讀取與搜尋推特、Reddit、YouTube、GitHub、B站、小紅書，不必付各平台 API 費。定位是能力層，附 `agent-reach doctor` 診斷。

- 注意：Reddit 沒有零配置路徑，必須登入態。
- 注意：作者已下架抖音、微博、微信公眾號（上游失修），依賴的上游容易壞。
- 來源：[dev.co](https://dev.co/ai/mcp/agent-reach)

### #5 Univer（dream-num）

1.0 版把 Sheets、Docs、Slides、Boards、Bases、PDF 六種編輯器整合成一個可程式化的 Office SDK，並提供 AI SDK，讓 agent 讀寫文件、更新公式、產生圖表。

- 注意：面向開發者，用來嵌入產品，不是拿來直接當 Office 用。
- 來源：[newreleases.io](https://newreleases.io/project/github/dream-num/univer/release/v1.0.0)

### #6 HyperFrames（HeyGen）

把 HTML、CSS、媒體與可 seek 的動畫轉成確定性 MP4，底層用瀏覽器加 FFmpeg。和 Remotion 的差別：用 HTML 而非 React，不需要 build。

- 教 agent 使用：`npx skills add heygen-com/hyperframes`
- 來源：[GitHub](https://github.com/HycJack/hyperframes)

### #7 MoneyPrinterTurbo

給一個主題就產生短影音：LLM 寫腳本 → 配音與字幕 → 取用素材 → 合成影片。

- 注意：只自動化組裝，不判斷品質；素材授權與平台規範要自己把關。
- 來源：[verdent.ai](https://www.verdent.ai/zh-Hant/guides/moneyprinterturbo-github)
