# 🧨 火藥庫 — 工具收藏

Oct 7, 2026 · @ioksengtan

## 使用方式

火藥庫收錄看到就想存起來的工具，等哪個點子需要時再來翻。新工具在總覽表加一列、在工具卡補一張，編號接續往下。

- **類別**：語音、Agent 基礎建設、多 agent 模擬、資料取得、文件編輯、影片生成、圖像風格化、提示詞，之後可自行增加。
- **狀態**：未試 → 試過 → 在用，試完記得改。
- **授權**：先看這欄再決定能不能包進對外服務，AGPL 特別留意。

## 工具卡

### #1 VoiceStudio（debpalash）

開源、完全本機運行的語音 AI 桌面應用，前身叫 OmniVoice Studio。提供相容 OpenAI 的本機 API，也有 MCP server。

- 注意：AGPL-3.0，若包成網路服務，修改部分要開源。
- 來源：[everydev](https://www.everydev.ai/tools/voicestudio/llms.txt)

### #2 Hindsight（vectorize-io）

Agent 記憶系統，重點是「學習」而非只存對話。分成世界事實、經驗、觀察等記憶網路，agent 可反思經驗、避免重複犯錯。核心操作是 Retain、Recall、Reflect。

- 注意：LongMemEval 91.4% 是廠商自報數字。
- 來源：[vectorize.io](https://vectorize.io/hindsight)

### #3 Paperclip

Node.js 伺服器加 React UI，把一群 AI agent 組織成公司：組織圖、預算、目標、治理與稽核紀錄。它不取代 Claude Code 或 OpenClaw，而是管理它們。

- 安裝：`npx paperclipai onboard --yes`
- 注意：「零人類公司」偏行銷，實用價值在多 agent 的成本與任務管理。
- 來源：[jimmysong.io](https://jimmysong.io/ai/paperclip)

### #4 Agent-Reach

Python CLI，讓 agent 讀取與搜尋推特、Reddit、YouTube、GitHub、B站、小紅書，不必付各平台 API 費。定位是能力層，附 `agent-reach doctor` 診斷。

- 注意：Reddit 沒有零配置路徑，必須登入態。
- 注意：作者已下架抖音、微博、微信公眾號（上游失修），依賴的上游容易壞。
- 來源：[dev.co](https://dev.co/ai/mcp/agent-reach)

### #5 Univer（dream-num）

1.0 版把 Sheets、Docs、Slides、Boards、Bases、PDF 六種編輯器整合成一個可程式化的 Office SDK，並提供 AI SDK，讓 agent 讀寫文件、更新公式、產生圖表。

- 注意：面向開發者，用來嵌入產品，不是拿來直接當 Office 用。
- 來源：[newreleases.io](https://newreleases.io/project/github/dream-num/univer/release/v1.0.0)

### #6 HyperFrames（HeyGen）

把 HTML、CSS、媒體與可 seek 的動畫轉成確定性 MP4，底層用瀏覽器加 FFmpeg。和 Remotion 的差別：用 HTML 而非 React，不需要 build。

- 教 agent 使用：`npx skills add heygen-com/hyperframes`
- 來源：[GitHub](https://github.com/HycJack/hyperframes)

### #7 MoneyPrinterTurbo

給一個主題就產生短影音：LLM 寫腳本 → 配音與字幕 → 取用素材 → 合成影片。

- 注意：只自動化組裝，不判斷品質；素材授權與平台規範要自己把關。
- 來源：[verdent.ai](https://www.verdent.ai/zh-Hant/guides/moneyprinterturbo-github)

### #8 Primitive（fogleman）

Go 寫的 CLI，一次加一個幾何形狀，每次挑讓誤差最小的那個，逐步逼近原圖。約 50～200 個形狀就有辨識度的抽象風格。形狀有三角形、矩形、橢圓、圓、旋轉矩形、貝茲曲線、多邊形等，也能自己實作 Go interface 加新形狀。

- 安裝與用法：`go get -u github.com/fogleman/primitive`，`primitive -i input.png -o output.png -n 100`
- 常用參數：`-n` 形狀數、`-m` 形狀模式（0 combo、1 三角形…）、`-a` 透明度、`-r` 輸入縮放（預設 256）、`-s` 輸出尺寸（預設 1024）
- 輸出：PNG、JPG、SVG、動畫 GIF；檔名含 `%d` 可存每一格，`-o` 可重複指定多種格式
- 注意：輸入圖建議小（約 256px）；GIF 需要 ImageMagick 的 `convert`；頁面沒說明是否仍在維護（約 13.5k stars、35 個 open issue）。
- 來源：[GitHub](https://github.com/fogleman/primitive)

### #9 MiroFish（666ghj）

多 agent 預測引擎。輸入新聞、政策草案、金融訊號或小說等素材，建出一個由有個性與記憶的 agent 組成的模擬世界，可注入變數觀察走向，最後產出預測報告與可互動的模擬。底層模擬引擎是 CAMEL-AI 的 OASIS，流程包含 GraphRAG 建圖、人設生成、雙平台並行模擬，以及能和 agent 對話的 ReportAgent。

- 安裝：`cp .env.example .env` → `npm run setup:all` → `npm run dev`（前端 3000、後端 5001）；或 `docker compose up -d`
- 需求：Python 3.11～3.12（uv）、Node 18+、OpenAI SDK 相容的 LLM API（官方推薦 Qwen-plus）、Zep Cloud 的 API key
- 注意：AGPL-3.0，包成網路服務要開源修改部分。
- 注意：很吃 token，官方建議先跑少於 40 輪；依賴外部 LLM 與 Zep Cloud。
- 注意：頁面沒有準確度驗證，財經與政治預測範例標示「coming soon」，預測結果當情境推演，別當成可信預測。
- 注意：約 77.6k stars，但 Releases 為空、看不到最近更新日期，維護狀況不明。
- 來源：[GitHub](https://github.com/666ghj/MiroFish)

### #10 prompts.chat（f）

前身是 Awesome ChatGPT Prompts，社群維護的開源提示詞庫，適用 ChatGPT、Claude、Gemini 等。內容有網站、CSV、Markdown、Hugging Face dataset 幾種取得方式，另附免費的《Interactive Book of Prompting》（28 章以上）。程式碼是 MIT，提示詞內容與資料是 CC0 公有領域，可放心拿去用。

- 使用：網站 prompts.chat；CLI `npx prompts.chat`；Claude Code plugin `/plugin marketplace add f/prompts.chat`；MCP server 遠端 `https://prompts.chat/api/mcp` 或本機 `npx -y prompts.chat mcp`
- 自架：`npx prompts.chat new my-prompt-library`，Next.js + TypeScript，需要 PostgreSQL 和登入方式（GitHub、Google 或 Azure AD）；有 Docker 支援
- 注意：提示詞品質取決於社群投稿，要自己挑；自架要處理資料庫與登入設定。
- 注意：約 172k stars、29 個 open issue，頁面看不到最近的更新節奏。
- 來源：[GitHub](https://github.com/f/prompts.chat)
