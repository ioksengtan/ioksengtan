# 互動式咖啡店手繪平面圖

記錄日期：2026-09-20
靈感來源：Instagram 帳號 `createwithconsta...` 的 Figma 製作短片
## 點子

以手繪黑白線稿製作咖啡店俯視平面圖，但不只是靜態空間示意：門可以逐步打開、菜單可以展開、植物可以澆水、洗手台可以出現使用狀態、蛋糕可以被取走。使用者在手機上點擊場景中的物件，就能看到短動畫或狀態變化。

這是一種介於以下形式之間的作品：

- 室內空間提案。
- 手繪資訊圖。
- 互動式繪本。
- Point-and-click 小遊戲。
- 品牌網站或社群宣傳內容。

## 從照片拆解出的做法

### 1. 先建立物件狀態表

每個會互動的物件都不是單張圖，而是一排連續狀態：

- `Door`：從完全關閉到逐步打開，至少十個角度／frame。
- `Menu`：立式菜單 → 攤開的平面菜單 → 收回。
- `Plant`：普通盆栽 → 澆水壺出現 → 水滴落下 → 完成。
- `Sink`：空洗手台 → 杯盤出現 → 清洗中的不同狀態。
- `Cake`：完整蛋糕／飲料 → 被拿走或狀態改變。

從畫面中紫色菱形圖示判斷，這些物件很可能使用 Figma component／variant 製作。

### 2. 將元件拼成俯視咖啡店

場景包含：

- 入口與門。
- 戶外座位／植栽。
- 長桌、吧台座位和雙人桌。
- 咖啡機與工作檯。
- 洗手台、冰箱、展示櫃。
- 菜單立牌。
- 植物、層架、杯具與裝飾。

每個元件保持同一種略帶抖動的黑色手繪線條，並以白底構成統一視覺。

### 3. 在 Figma Prototype 中連接狀態

可能採用以下互動：

```text
On Tap
  → Change to 下一個 variant
  → Smart Animate
  → 短延遲後 Change to 下一格
```

門這類連續動作可以串接多個 variant；菜單則可用兩三個 variant 完成展開。若元件需要回到初始狀態，可在最後一格加入 `After delay`，或再次點擊時反向播放。

## 為什麼這個形式有趣

### 空間圖變成可探索的故事

一般平面圖只告訴人家具在哪裡；加入互動後，使用者會主動尋找「還有什麼可以點」，因此開始注意場景細節。

### 不需要遊戲引擎

只用 Figma 就能完成素材、元件狀態、動畫與手機 prototype，適合設計師快速驗證體驗，不必先寫程式。

### 手繪感降低介面距離

精準 CAD 圖容易讓人把它當工程文件；手繪線稿更像店主的想像或旅行筆記，適合咖啡店、選物店、展覽和個人品牌。

### 素材可重複組合

建立一套門、桌椅、櫃台、植物和食物元件後，就能快速拼成不同店面、房間或城市街區。

## Figma 實作結構

### Component sets

```text
Door
├─ state=closed
├─ state=open-15
├─ state=open-30
├─ state=open-45
├─ state=open-60
└─ state=open

Menu
├─ state=board
├─ state=opening
└─ state=open

Plant
├─ state=idle
├─ state=watering-1
├─ state=watering-2
└─ state=watered
```

每個 variant 的 frame 大小和物件 anchor 必須一致，Smart Animate 才不會跳動。元件名稱、圖層名稱和向量節點結構也應盡量一致。

### Prototype flow

- 主場景設成手機橫向 frame。
- 互動物件用 component instance 放入場景。
- 優先用 `Change to`，避免每個狀態都複製完整咖啡店 frame。
- 點擊範圍可比線稿稍大，另放透明 hit area，提升手機操作性。
- 使用 subtle sound 或 haptic 時需另行開發；Figma prototype 先驗證視覺與流程。

## 可發展的版本

### 店面介紹

- 點菜單查看品項與價格。
- 點座位查看插座、容納人數和預約狀態。
- 點咖啡機播放沖煮動畫。
- 點門進入下一個房間。
- 點 QR code 開啟導航或訂位。

### 室內設計提案

- 比較白天／夜晚燈光。
- 切換不同家具配置。
- 顯示顧客和店員的動線。
- 模擬排隊、取餐與回收流程。
- 用互動展示「為何家具要放在這裡」。

### 小遊戲

- 找到所有可互動物件。
- 幫植物澆水、清理杯盤、補充蛋糕。
- 在時間內完成開店準備。
- 找出藏在場景中的角色或物品。
- 每次點擊累積店鋪從空間到營業中的變化。

### 個人生活地圖

- 自己的房間或工作桌。
- 旅行住過的旅館。
- 家中每個物件背後的故事。
- 理想工作室或夢想店面。
- 以年度更新方式記錄空間的變化。

## 可做成的素材產品

建立一套 **Interactive Hand-drawn Space Kit**：

- 門窗與牆面。
- 各種桌椅和層架。
- 廚房、咖啡和餐飲設備。
- 植物、燈具和裝飾。
- 人物、寵物和食物。
- 每個物件附 2–10 個 interaction variants。
- 預先設定 Figma prototype 動畫。

使用者只需拖放元件，就能製作自己的互動房間、店面或展覽地圖。可同時提供純 SVG、Figma library 與網頁版本。

## MVP 建議

先只做一個房間和五個互動物件：

1. 可開關的門。
2. 可展開的菜單。
3. 可澆水的植物。
4. 可取走的蛋糕。
5. 會冒煙的咖啡杯。

限制每個動作最多五格，完成手機 prototype 後交給三個人測試：

- 他們是否知道物件可以點？
- 是否能發現五個互動？
- 動畫是否太慢或太細小？
- 看完後是否更記得空間和品牌？

若使用者不知道哪裡能點，不要立刻在每個物件上加按鈕；可以先用微小 idle motion、游標／觸控回饋、第一次進入時的提示，保留探索感。

## 從 Figma 走向正式產品

Figma 適合 prototype，但若要公開為互動網站或長期遊戲，可將元件輸出為 SVG：

- Web：SVG＋CSS／JavaScript，或 React component state。
- 動畫：Rive、Lottie 或 GSAP。
- 遊戲：Phaser、Godot 或 Unity。
- 無程式平台：Framer、Webflow 搭配 interactions。

正式版需要補上 keyboard navigation、可見 focus、文字替代、reduced motion 和螢幕閱讀器說明，因為純點擊圖像對無障礙使用者並不友善。

## 可與其他點子結合

- 將 `今日鳥訪客電子紙畫框` 的每日鳥種放進窗外或屋頂，形成會隨真實環境改變的咖啡店場景。
- 將點子 repository 畫成一間可探索工作室，每個家具代表一個分類。
- 將 Agents Office／Bot Crossing 的工作狀態改用手繪空間，而不是 3D 世界，降低製作和運算成本。
- 將電子活動識別證的場地地圖做成這種互動線稿，點擊攤位即可看到任務與資訊。

## 最終判斷

這個作品最值得參考的是：互動不一定要看起來像 app。只要讓插畫中的物件具備狀態，平面圖就能成為介面，空間也能成為故事。Figma component variants 很適合在低成本下驗證這種體驗。
