# 舊 Kindle 電子紙打字機

記錄日期：2026-10-02

## 靈感來源

Roni Bandini 的開源專案 **Kindle Typewriter**，將越獄後的 Kindle Paperwhite 放進帶有熱感印表機的 3D 列印底座，讓原本用來閱讀文字的裝置轉變成輸入並印出文字的打字機。

- GitHub：<https://github.com/ronibandini/Kindle-Typewriter>
- 完整製作說明：<https://www.hackster.io/roni-bandini/turn-an-old-kindle-into-a-typewriter-aaeabb>
- 授權：MIT

## 原專案如何運作

這不是把 USB 或藍牙鍵盤直接接到 Kindle，而是一個由兩台裝置分工的系統：

1. Kindle Paperwhite 越獄後安裝 KUAL 與 kterm。
2. Kindle 執行 Bash 寫成的極簡輸入介面。
3. 使用者在 Kindle 上輸入文字；連續輸入兩個換行後，文字緩衝區透過 HTTP 傳送出去。
4. 同一 Wi-Fi 網路上的 Raspberry Pi Zero 2 W 執行 Flask 服務。
5. Raspberry Pi 經由 serial 控制熱感印表機，把文字立即印出。
6. 系統會依紙張寬度換行，避免拆開單字，也會保存先前印出的文字。

### 原型所需材料

- 一台可越獄的 Kindle Paperwhite。
- Raspberry Pi Zero 2 W。
- 嵌入式熱感印表機。
- 5V／3A 電源。
- 兩件式 PLA 3D 列印外殼。
- Kindle 與 Raspberry Pi 可連線的 Wi-Fi 網路。

## 這個點子有趣的地方

### 從消費文字變成生產文字

Kindle 原本是高度封閉、以閱讀為目的的產品。改造後保留電子紙的慢節奏和低干擾感，卻把核心行為反轉為寫作。

### 數位文字立即物質化

文字不是儲存在另一個雲端筆記 App，而是在完成一個段落後直接變成紙條。這個限制讓寫作更像打字機、詩籤或即時出版工具。

### 延長舊硬體生命

舊 Kindle 仍有可用的電子紙面板、電池、觸控和 Wi-Fi。以軟體與外接運算模組重新分工，比拆出電子紙面板重新驅動更容易完成。

## 限制與風險

- 必須先確認 Kindle 型號與韌體是否有安全且可逆的越獄方式；錯誤操作可能使裝置無法使用。
- Kindle 上是受限的 BusyBox／Bash 環境，開發和除錯不如一般 Linux 電腦方便。
- 原專案需要 Kindle 與 Raspberry Pi 位於同一個 Wi-Fi 網路，並非完全獨立的離線設備。
- 原型使用螢幕輸入，並沒有解決實體鍵盤直連 Kindle 的問題。
- 熱感紙不適合長期典藏；若目標是保存文章，仍需同步純文字檔。
- 部分熱感紙可能含 BPA 或 BPS，應選擇標示不含酚類的耗材並減少不必要的皮膚接觸。

## 可延伸的產品方向

### 專注寫作版

加入實體鍵盤，讓 Raspberry Pi 同時負責鍵盤輸入、文件保存和列印；Kindle 只作為電子紙顯示終端。這會比嘗試讓 Kindle 原生支援各種 USB／藍牙鍵盤更穩定。

### 每日一句儀式

每天只允許寫一段話，完成後印成紙條。紙條可投入盒中，在月底或年底重新閱讀。

### 詩籤與故事機

輸入幾個詞後，由本地小模型或遠端服務協助生成短詩、故事開頭或角色對白，再由熱感印表機輸出。AI 功能應是可選層，不影響離線寫作核心。

### 活動留言站

放在婚禮、展覽、咖啡店或工作坊，讓訪客寫一句話並取得一張實體副本；系統同時保存匿名文字，形成活動共同日誌。

### 無印表機輕量版

若目標只是低干擾寫作，可省略印表機與大型底座：用 Raspberry Pi 或其他小型電腦接鍵盤，在瀏覽器或 Kindle 終端顯示文字，並自動同步 Markdown 檔案。

## 建議 MVP

1. 先確認手上的 Kindle 型號、韌體與越獄相容性。
2. 不急著製作外殼，先讓 Kindle 和一台現有電腦完成 HTTP 傳字。
3. 再以 Raspberry Pi Zero 2 W 取代電腦，將文字同時寫入本地檔案。
4. 接上熱感印表機，測試中文字型、紙寬、自動換行與編碼。
5. 最後才設計 Kindle、鍵盤、印表機和紙捲的共同外殼。

## 與既有點子的關係

- 與「E-Ink 螢幕打字訓練裝置」同樣利用電子紙降低干擾，但這個版本更重視舊硬體再利用與紙本輸出。
- 可借用「量產標準件負責功能，3D 列印負責造型與介面」的方法：Kindle、Raspberry Pi 和印表機維持原模組，外殼只負責固定、走線和使用姿勢。
- 若未來加入本地小模型，可參考卡片大小本地大模型電腦的選型研究，但不應讓 AI 成為基本打字功能的必要依賴。

## 一句話定位

讓退役 Kindle 從閱讀器變成一台慢速、低干擾、能把文字立即印成紙條的再生打字機。
