# 手寫打字機 網頁版規格（中文・瘦金體）

更新日期：2026-10-08  
對應點子：第 75 號[手寫打字機](手寫打字機.md)  
狀態：規格草案／尚未開工  
紀錄者：Maker Idea

## 1. 目標

在瀏覽器裡用中文輸入法打字，字以瘦金體風格「一筆一畫」寫在一張紙上，並可匯出為單線筆跡 SVG，供日後接 XY 繪圖機使用。

先驗證三件事：
1. 打字加筆畫動畫的體驗好不好玩。
2. 瘦金體的特徵能否用程式參數做出來（不靠現成字體輪廓）。
3. 輸出的筆路是否能直接當繪圖機資料。

## 2. 非目標（第一版不做）

- 不接硬體、不產生 G-code。
- 不做多字體選擇，只做瘦金體一種風格。
- 不做帳號、雲端儲存、分享連結。
- 不做簡體字與日文專屬字形的特別處理。

## 3. 使用情境

- 在頁面中央的紙張上打字，每確認一個字，該字就開始被「寫」出來。
- 可切換直書（由右至左、由上到下）或橫書（由左至右）。預設直書，符合瘦金體傳統書寫形式。
- 打完後下載 SVG，或直接重播整頁書寫過程。

## 4. 功能需求

### 4.1 輸入

- 使用一個隱藏的文字輸入框承接系統輸入法（注音、倉頡、拼音皆可），不自製輸入法。
- 只處理「已確認」的文字：輸入法組字中（composition 進行中）不寫，組字結束事件觸發後才把確認的字送入書寫佇列。
- 支援 Enter 換行（直書即換欄）、Backspace、貼上文字。
- 英數與標點：第一版只支援常用全形標點（，。、？！「」）與阿拉伯數字；其他字元以方框佔位。

### 4.2 字形與筆順

- 筆順與每一筆的中心線資料來源：開源的 Make Me a Hanzi／Hanzi Writer 資料（每字含筆畫順序與中軸線）。涵蓋範圍與授權條款開工前需查證，並在專案內註明出處。
- 資料沒有的字：以灰色方框佔位，並在畫面提示「缺字」，不中斷其他字。
- 每一筆表示為一條有序折線／曲線（中心線座標，單位為字格內 0–1 正規化）。

### 4.3 瘦金體筆跡生成

用「中心線加參數化筆寬輪廓」產生，而不是填滿字體輪廓。理由：中心線同時是日後繪圖機要走的路徑。

瘦金體特徵與對應的第一版做法（特徵描述為一般書法常識，實作參數需看實際效果調整）：

- 筆畫整體細挺、轉折處銳利：基本筆寬固定偏細，並帶輕微起伏。
- 起筆有頓筆：每筆起點加一個小圓點或三角形的加粗，後接細線。
- 收筆尖細：筆畫尾端寬度漸縮至接近零，撇、捺、豎鉤尤其明顯。
- 橫畫略向右上、尾端有明顯頓點；豎畫挺直。
- 字形瘦長、重心偏上，筆畫舒展。
- 每個字加入微小隨機擾動（位置、傾斜、筆寬），避免像印刷字，但同一個字在同一頁重現時使用固定種子，以便重播時一致。

這部分是整個點子最大的風險：中軸線資料來自一般楷體，不是瘦金體，所以先做到「風格像」，不求字形逐字還原。若效果不佳，退路是改用有授權的瘦金體字型輪廓，以遮罩依筆順掃出的方式呈現（輸出就不再是單線路徑）。

### 4.4 動畫

- 每一筆依序「長出來」：沿中心線推進一個筆尖點，筆寬依輪廓參數變化。
- 速度：預設每字約 0.6 至 1.2 秒，筆與筆之間有短暫停頓；可調速度滑桿。
- 書寫佇列：打字快於書寫時排隊，不丟字；佇列長度顯示在角落。
- 筆尖用一個小筆形游標跟隨，增加手寫感。
- 可選的打字機音效，預設關。

### 4.5 版面

- 紙張尺寸：預設 A5，可選 A4。單位用毫米。
- 字格大小預設 12 mm，行距與字距可調。
- 直書：由右而左換欄；橫書：由上而下換行。
- 滿頁後停止書寫並提示，不自動翻頁。

### 4.6 刪除與重播

- Backspace：刪除最後一個字，畫面上以反向動畫把該字「收回」（網頁版可行；日後接硬體時墨水無法收回，需另訂策略，例如先緩衝一個字再下筆）。
- 重播按鈕：清空紙面，依相同種子把整頁重新寫一遍。

### 4.7 匯出

- 下載 SVG：每一筆是一個 path 元素，依書寫順序排列，座標單位毫米，頁面尺寸與紙張一致，筆寬資訊以單線 path 提供（`stroke-width` 為固定值），並另提供含變寬輪廓的視覺版（兩種檔案或兩個圖層）。
- 下載 PNG 預覽（選配）。

## 5. 非功能需求

- 純前端靜態網頁，不需要伺服器，可直接放在本站的 GitHub Pages 上。
- 不依賴大型框架；筆畫繪製用 SVG 或 Canvas 擇一（建議 Canvas 做動畫，另以資料產生 SVG 匯出）。
- 手機瀏覽器可用（注音輸入法在手機上較常見），觸控裝置的虛擬鍵盤需能彈出。
- 字資料依需要載入（逐字或分塊），首次載入量要小，不一次下載整個字庫。
- 繁體中文介面。

## 6. 資料格式（內部）

```
Page { paper: "A5", direction: "vertical", seed: 1234, glyphs: Glyph[] }
Glyph { char: "永", col: 0, row: 3, strokes: Stroke[] }
Stroke { points: [x, y][], kind: "橫" | "豎" | "撇" | "捺" | "點" | "挑" | "鉤" | "折", width: number[] }
```

`kind` 由資料或規則判斷，用來決定頓筆與收筆的形狀；第一版若無法自動分類，統一用預設輪廓。

## 7. 驗收條件

- 輸入「永字八法」「天地玄黃」等短句，能依筆順完整寫出，無缺筆或亂序。
- 注音輸入法組字過程中不會寫出任何殘字。
- 連續快速貼上 100 字，不當機、不掉字。
- 匯出的 SVG 在一般向量軟體中可開啟，筆畫順序與動畫一致，尺寸與選定紙張一致。
- 同一段文字、同一種子重播兩次，結果完全相同。
- 肉眼可辨識「細挺、頓筆、尖收」三個瘦金體特徵。

## 8. 里程碑（建議）

1. 筆畫資料載入與單字筆順動畫（不分風格，等寬線條）。
2. 加入瘦金體筆寬輪廓與擾動，調到風格可接受。
3. 版面、直橫書、輸入法整合、書寫佇列。
4. Backspace、重播、匯出 SVG。
5. 手機實測與效能調整。

## 9. 待查證與待決定

- Make Me a Hanzi／Hanzi Writer 資料的授權與繁體字涵蓋率（開工前先查）。
- 是否另有授權清楚的瘦金體字型可作為退路，或作為風格參考。
- 預設輸出要不要同時提供「單線」與「變寬」兩種。
- 接硬體時墨水無法收回，Backspace 策略如何定。
- 英文與數字是否要有對應的細挺風格字形。
