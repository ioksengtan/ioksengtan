# 近期電子專案成本比較

估算日期：2026-10-03

## 估算口徑

- 金額以台幣計，採 `US$1 ≈ NT$32` 作為採購預算換算，而非即時匯率報價。
- 「最低可動原型」以功能能驗證為準，不追求完整外殼、漂亮走線或長期可靠性。
- 「照片級完整原型」包含電池、電源、接頭、線材、固定件與 3D 列印／透明板材等容易漏算的項目。
- 不計開發工具、焊台、3D 印表機、人工與反覆失敗的時間；若委外列印、雷切或焊接，需另外加價。
- 海外小量採購建議再保留 15～30% 運費、耗損與備料預算。

## 1. 舊 Kindle 電子紙打字機

假設已有一台可越獄的 Kindle。

| 項目 | 預估 |
| --- | ---: |
| Raspberry Pi Zero 2 W | NT$500～1,000 |
| 嵌入式熱感印表機 | NT$1,400～1,800 |
| 5V／3A 電源、microSD、線材 | NT$450～800 |
| PLA 外殼與固定件 | NT$300～900 |
| 熱感紙 | NT$50～150 |
| 合計 | **NT$2,700～4,650** |

官方 Pi Zero 2 W 定價為 US$15；Seeed 的嵌入式熱感印表機單體為 US$45，這兩項已占最低材料費約 NT$1,920。實際在台灣零買、加上電源和運費後，抓 NT$2,500～4,000 才合理。

若只是驗證 Kindle 傳字，可先用既有電腦取代 Pi、把文字寫入檔案，材料成本近乎為零。確認越獄、中文字型和傳輸流程後才買印表機，能避免最昂貴的錯買。

## 2. ESP-NOW 穿戴式距離感應器

| 項目 | 預估 |
| --- | ---: |
| LILYGO T-QT Pro × 2 | NT$580～900 |
| 小型 LiPo × 2 | NT$250～500 |
| 外殼、背夾或掛繩 | NT$200～600 |
| 線材、開關與運費分攤 | NT$200～500 |
| 合計 | **NT$1,230～2,500／一對** |

T-QT Pro 官方單價約 US$9.05，所以它是少數主板已經包含彩色螢幕、按鍵與充電功能，仍可把一對控制在千元上下的方案。若先用 USB 供電、裸板測試，約 NT$800～1,200 就能完成核心功能。

最容易低估的是兩顆尺寸合適的電池和穿戴外殼。RSSI 只適合做遠／中／近互動，若改成真正精準測距的 UWB，整體成本通常會明顯上升。

## 3. NFC 教室銀行

| 項目 | 10 人測試 | 30 人班級版 |
| --- | ---: | ---: |
| NTAG213 卡／貼紙 | NT$100～300 | NT$300～900 |
| 卡面印刷、護卡或卡套 | NT$100～300 | NT$300～900 |
| NFC 寫入 | 使用既有手機 | 使用既有手機 |
| 試算表／簡易網站 | 免費模板起步 | 免費模板起步 |
| 合計 | **NT$200～600** | **NT$600～1,800** |

海外品牌零售的 NTAG213 白卡約 US$2.95，10 張以上約 US$2.66；但一般無印刷白卡或貼紙大量採購會更便宜。若教師已有 NFC 手機，這個案子幾乎沒有電子 BOM，成本主要是卡面、帳戶建立、權限和交易流程。

若另買教師平板、獨立讀卡器，或開發真正有登入與稽核的後台，預算會上升到 NT$3,000～8,000 以上；此時軟體工時遠高於硬體費。

## 4. 閉環控制桌上型智慧溫室

### 先做單一澆水迴路

| 項目 | 預估 |
| --- | ---: |
| ESP32 開發板 | NT$200～400 |
| 溫濕度＋電容式土壤感測 | NT$250～500 |
| 水泵、軟管、滴頭、水箱 | NT$300～700 |
| MOSFET／繼電器、低水位與漏水保護 | NT$250～600 |
| 電源、線材與盒體 | NT$400～800 |
| 合計 | **NT$1,400～3,000** |

### 做到照片中的完整感

再加入微型鋁擠型與透明板 NT$1,500～3,500、風扇 NT$150～350、伺服與連桿 NT$200～600、螢幕 NT$150～500、植物燈與電源 NT$500～1,500，總價約 **NT$4,000～8,000**。

若採用品質較好的溫濕度、流量、漏水、光照感測器，並把水電隔離、接頭和維修性做完整，應直接抓 **NT$8,000～15,000**。它不是主板昂貴，而是每增加一個自動動作，都要同時增加感測、驅動、供電、故障保護和機構。

最省錢的方式是先不用鋁框、不做自動窗與補光，只做「土壤乾燥 → 短時間澆水 → 等待後重測」的一盆植物版本。

| 受保護 LiPo | NT$250～500 |
| microSD、喇叭、線材與螺絲 | NT$250～550 |
| 多色 3D 列印外殼與磁鐵 | NT$300～900 |

Waveshare 官方頁面依版本約 US$29.99～39.99。由於螢幕、觸控、RTC、microSD、音訊與電源管理已集中在一塊板上，雖然單板價格最高，整體反而容易控制，約 NT$2,000～3,500 就能做出接近成品的展示效果。

真正的產品成本還要加角色美術、動畫、韌體與測試時間。若商品化，必須重新製作原創角色與外殼，不能直接使用 Pokémon 素材與非商用模型。

| 項目 | 預估 |
| --- | ---: |
| Pico 2／ESP32-C3 開發板 | NT$160～350 |
| 單色 OLED 或小型 TFT | NT$100～400 |
| 大按鍵、蜂鳴器、開關 | NT$80～200 |
| 電池與充電保護 | NT$180～400 |
| 萬用板／PCB、線材、外殼 | NT$250～800 |
| 合計 | **NT$770～2,150** |

Pico 2 官方定價 US$5，ESP32-C3 官方開發板參考價約 US$8；因此麵包板加 USB 供電的功能原型可壓到 NT$500～900。做到可攜、耐摔、按鍵手感穩定的版本，則應抓 NT$1,200～2,500。

這個案子最適合先做，因為程式、電路和外殼都小；即使最後不繼續，螢幕、按鍵和主板也容易拆去其他專案重用。

## 建議開發順序

1. **單鍵掌機**：最低風險，最快驗證完整產品循環。
2. **ESP-NOW 距離感應器**：用很少零件做出明顯的雙機互動。
3. **圓形螢幕虛擬寵物球**：最適合做可展示、可分享的漂亮作品。
4. **NFC 教室銀行**：硬體便宜，但要先有真實教學場景與資料權限設計。
5. **Kindle 打字機**：先確認手邊 Kindle 型號可越獄，再決定是否買印表機。
6. **智慧溫室**：最後做；它需要最長的連續測試，失敗也可能傷植物或漏水。
