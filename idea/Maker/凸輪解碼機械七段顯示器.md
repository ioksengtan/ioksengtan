# 凸輪解碼機械七段顯示器

記錄日期：2026-10-03

## 靈感來源

Instagram 帳號 `beker.david` 展示一座小型機械七段顯示器。左側減速馬達帶動齒輪組，中間有多片並排旋轉的凸輪與彈簧／連桿，上方七片白色顯示片依序翻轉，循環顯示數字 0～9。

## 核心原理

七段顯示器由 a～g 七個線段組成；每個數字只是七段亮／暗的不同組合。一般電子顯示器把這張真值表寫在晶片或程式中，這個機構則把它寫進凸輪外形：

1. 主軸每轉到一個固定角度，代表一個數字。
2. 軸上有七組凸輪，每組負責一個顯示段。
3. 該數字需要顯示某一段時，凸輪高點或溝槽把從動件推到「顯示」位置。
4. 不需要該段時，從動件由彈簧、重力或另一側輪廓復位。
5. 連桿把小幅直線位移轉換成上方顯示片約 90° 的翻轉。
6. 十個索引位置走完後，回到 0。

因此它同時包含：

- 十進位索引。
- 七路機械記憶／解碼。
- 凸輪與從動件。
- 旋轉轉直線／翻轉運動。
- 齒輪減速與同步。

## 從照片可觀察的結構

- 左側使用小型直流減速馬達，不是每片顯示段各裝一顆伺服。
- 主軸旁有一組較大的齒輪，負責降低速度與增加扭矩。
- 中央七組機構排列非常緊密，各自向上延伸成一條銅色連桿。
- 顯示片以白色正面和深色／側向隱藏面形成明暗差異，不需 LED。
- 底部可看到多個金屬彈簧或拉力元件，可能負責讓從動件貼緊凸輪。
- 左下方小電路板有旋鈕和指示燈，較像直流馬達調速／供電模組，而非七段解碼器。

## 顯示片設計

機械七段顯示最重要的不是把片子翻動，而是讓「關閉」狀態真的消失：

- 顯示面可貼白色、螢光或反光材料。
- 背面和支架使用深色，旋轉 90° 後只露出窄邊。
- 七片之間必須保留安全間隙，避免同步翻轉時相撞。
- 軸心間隙太大會造成數字歪斜；太緊則增加馬達負載。
- 連桿最好保留微量彈性或過載逃脫，避免凸輪卡死時折斷。

## 凸輪設計方法

### 真值表

先建立 0～9 每個數字需要顯示的線段：

| 數字 | 顯示線段 |
| --- | --- |
| 0 | a b c d e f |
| 1 | b c |
| 2 | a b d e g |
| 3 | a b c d g |
| 4 | b c f g |
| 5 | a c d f g |
| 6 | a c d e f g |
| 7 | a b c |
| 8 | a b c d e f g |
| 9 | a b c d f g |

每個數字分配 36°，再依每一段的開／關序列生成凸輪高低輪廓。不能直接用尖銳階梯：需要加入緩升與緩降角度，降低衝擊、摩擦和卡住的機率。

### 索引與停留

若畫面要在每個數字停住，單純連續馬達只會不停掠過中間狀態。可選：

- 槽輪／Geneva mechanism，使輸出間歇轉動。
- 棘輪與定位珠，每次前進一格。
- 步進馬達，每次轉 36°。
- 霍爾感測器或光遮斷器尋找零點，再以程式控制位置。

若只是展示凸輪連續動作，直流減速馬達＋速度控制器最簡單；若要成為時鐘或精準計數器，必須加入索引定位。

## 套件成本與難度

### 粗略材料成本

| 項目 | 預估 |
| --- | ---: |
| PLA／PETG 列印件與失敗耗損 | NT$250～600 |
| 減速馬達、聯軸器與調速板 | NT$180～400 |
| 金屬軸、螺絲、墊片、彈簧 | NT$180～450 |
| 木底板、電源與線材 | NT$150～350 |
| 材料合計 | **NT$760～1,800** |

真正昂貴的是列印、去支撐、研磨、校正和裝配時間。七組凸輪中只要一組摩擦稍大，整台就可能卡住。因此：

- 完整零件包合理售價約 NT$1,500～2,500。
- 已組裝與調校的成品可能需 NT$2,500～5,000 以上。
- 不適合作為第一個 NT$499 大眾套件。

### 500 元級的可能版本

可把產品拆成三級：

1. **數位設計包**：STL、凸輪生成表、組裝動畫與課程，NT$199～399。
2. **五金包**：馬達、軸、彈簧、螺絲與電路，不含列印件，NT$499～799。
3. **完整列印套件**：所有列印件與五金，NT$1,500 以上。

另一條路是只做一個顯示段的透明教學模型，讓使用者手轉凸輪觀察開／關，成本可降到 NT$499 內；之後再擴充為七段。

## 產品方向

### 機械時鐘

四組顯示器組成 HH:MM，但體積、噪音和零件數會增加四倍。可改成只有一位數翻動，搭配固定印刷刻度，降低複雜度。

### 訪客／完成次數計數器

每觸發一次就前進一格，適合展覽、工作室、打卡或習慣紀錄。機械動作本身就是獎勵回饋。

### 手搖解碼教具

取消馬達，讓學生轉動旋鈕，從透明側板觀察七組凸輪如何共同產生數字；可連結布林真值表、凸輪、連桿和機械計算。

### 可換字形鼓

將凸輪軸設計成可抽換卡匣，不同卡匣可以顯示倒數、特定序列或簡單符號，形成「機械程式卡」。

### 巨型公共顯示

放大顯示片但保留小型凸輪控制器，以鋼索或連桿遠端帶動，可成為店面號碼牌或公共藝術。

## 製作風險

- 3D 列印軸孔尺寸、層紋摩擦和翹曲會累積成同步誤差。
- 七組彈簧張力過大會讓馬達負載相加；太小又會讓從動件離開凸輪。
- 凸輪壓力角過大會卡住或磨損。
- 所有齒輪和凸輪必須有清楚的相位對齊標記。
- 顯示片高速翻轉可能夾手或飛脫，外層應加透明護罩。
- 若長時間展示，需考慮潤滑、PLA 蠕變、馬達過熱和噪音。

## 與既有點子的連結

- 與「手動拉桿式復古列車資訊看板」同樣用機械動作顯示資訊。
- 可將「魔術方塊結構萬年曆」的日期功能改成凸輪解碼數字。
- 與 D10 機械骰子計數器同樣把離散狀態寫進實體機構。
- 可作為硬體套件平台的高階機構盒，而不是 499 元入門電子盒。

## 一句話定位

把七段顯示器的數字真值表雕刻進七組凸輪，用一顆馬達和純機械連桿把旋轉位置解碼成會翻動的實體數字。
