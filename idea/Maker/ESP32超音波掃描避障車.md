# ESP32 超音波掃描避障車

記錄日期：2026-09-20  
靈感來源：Instagram 短片截圖

## 點子

製作一台以 ESP32 為控制核心的四輪自主小車，在車頭將超音波距離感測器安裝於微型 servo 上。感測器可以像頭部一樣左右轉動，量測不同方向的距離，再決定前進、停止、倒車或轉向。

相較於在車頭固定一顆距離感測器，旋轉掃描能用較少感測器取得左、中、右三個方向的資訊，也讓機器人的判斷過程容易被人看懂。

## 從照片可辨識或合理推測的組件

- 雙層透明壓克力四輪小車底盤。
- 四顆黃色 TT 減速馬達與輪胎，形成四輪差速驅動。
- ESP32 開發板。
- 雙 H-bridge 馬達驅動模組；外形看起來可能是 L298N 類型，實際型號需確認。
- HC-SR04 類型超音波感測器。
- SG90 類型微型 servo，負責轉動超音波感測器。
- 兩顆 18650 電池與電池座。
- DC-DC 降壓模組，供應控制器或 servo 所需電壓。
- 實體電源開關。
- 大量 Dupont 線與螺絲固定件。

## 基本行為

```text
持續量測正前方距離
    ↓
距離安全 → 前進
    ↓
發現障礙 → 停止
    ↓
servo 依序看左、中、右
    ↓
比較三個方向的距離
    ↓
向空間較大的方向原地轉彎
    ↓
重新朝前並繼續行駛
```

若左右都太近，可以先倒退一段距離，再重新掃描。

## 值得參考的設計

### 用一個感測器取得多方向資訊

旋轉超音波感測器成本低、程式直觀，也有明確的機器人「看向某處」動作。缺點是掃描需要時間，小車必須先停下，不能把它當作高速避障方案。

### 四輪差速轉向

左右兩側輪組以不同速度或相反方向旋轉，即可前進、後退、轉彎及原地旋轉，不需要複雜的機械轉向結構。

### 模組化電子層

底層負責馬達、電池和結構，上層放控制器、驅動器與電源模組，方便接線和修改。prototype 階段非常實用，但完成版應整理線材並保護電路板。

## 電路與安全重點

- ESP32 GPIO 通常不耐 5 V；若使用 5 V HC-SR04，`ECHO` 回傳腳應經分壓或 level shifter 降到 3.3 V。
- servo 不應直接由 ESP32 板上的 3.3 V pin 供電。
- 馬達、servo 和 ESP32 最好分開穩壓，但必須共地。
- 馬達啟動電流會造成電壓下降與 ESP32 reset；應選擇足夠電流的電源模組並加適當電容。
- 兩顆 18650 的串並聯方式、充電器與保護板必須相互匹配，不應直接用不明來源裸電芯。
- L298N 壓降與發熱較高；小車若追求續航，可改用 TB6612FNG 或其他 MOSFET 型驅動器。

## 軟體狀態機

建議避免以大量 blocking delay 控制，改成明確狀態：

- `FORWARD`：向前並定期量測。
- `BRAKE`：停止，等待車體穩定。
- `SCAN_LEFT`：servo 左轉並取多次中位數。
- `SCAN_RIGHT`：servo 右轉並取多次中位數。
- `DECIDE`：比較距離與歷史方向。
- `TURN_LEFT`／`TURN_RIGHT`：原地旋轉固定時間或角度。
- `BACK_UP`：無路可走時後退。
- `RECOVER`：感測器連續無有效回波時的容錯。

為避免小車在狹窄空間左右反覆猶豫，可加入 hysteresis：只有當另一方向明顯多出一定距離時才改變選擇，或記住上次轉向並在相近分數下保持同方向。

## 第一版 prototype

1. 先讓左右馬達組能分別前進與後退。
2. 校正兩側 PWM，使小車能大致直行。
3. 固定超音波感測器，只完成正面緊急停車。
4. 加入 servo，量測左、中、右三個角度。
5. 實作低速狀態機與死路倒退。
6. 最後才加入手機監看、地圖或自主探索。

建議掃描角度先用 `30° / 90° / 150°`，每個方向取 3–5 次有效讀值的中位數，不直接相信單次回波。

## 可發展方向

### 低成本自主 rover

- 加入紅外線循線感測器。
- 加入輪速 encoder，改善直行與轉彎精度。
- 加入 IMU，估計轉向角度。
- 以 ESP32 Wi-Fi 提供手機控制和即時距離圖。

### 小型掃描雷達

讓 servo 連續掃描多個角度，將角度與距離傳到瀏覽器，以極座標畫出周圍障礙。這不是真正 LiDAR，但很適合教學「感測、座標與視覺化」。

### M5Stack 整合

- 使用 Cardputer 當遙控器，鍵盤控制方向並顯示距離。
- 使用 CoreS3 顯示掃描雷達與電池狀態。
- 使用 AtomS3 作為更緊湊的車載控制器。

### 行為型機器人

除了避障，也可加入：

- 跟隨前方物體。
- 在固定距離內巡牆。
- 聽到聲音後轉向聲源。
- 找到最開闊方向並自主探索。
- 將「看左、看右、害怕、好奇」等內部狀態用動作或燈光表達。

## 和上一個 RC 底盤點子的關係

`3D列印迷你RC車模組化底盤` 偏向可拆修機械結構與齒條轉向；本題偏向電子控制、感測與自主行為。兩者之後可以合併：使用模組化 3D 列印底盤，再加上 ESP32 和旋轉距離感測器，形成一套可替換轉向、驅動與自主控制模組的 rover 平台。

## 待確認

- 照片中的馬達驅動器與 DC-DC 模組實際型號。
- 電池採串聯或並聯，以及是否包含 BMS／保護板。
- 感測器是否確為 HC-SR04，或是相容型超音波模組。
- 車上是否還有照片角度看不到的 Bluetooth、receiver 或其他感測模組。
