# 社群電子專案硬體套件平台

記錄日期：2026-10-03

## 問題

社群影片已經解決「讓人想做」的問題，真正阻止人動手的是：

- 不知道零件的正確名稱和版本。
- 每個零件來自不同賣場，運費可能高於零件。
- 螺絲、接頭、電池極性與尺寸容易買錯。
- 買完仍需焊接、燒錄、校正和列印外殼。
- 專案結束留下大量只用一次的散裝零件。

因此可以賣的不是一袋元件，而是「把靈感變成第一次就能完成的路徑」。

## 一句話定位

把社群上令人心動的電子作品，轉成不用查料、不怕買錯、拆盒就能開始的限量專案套件。

## 市場上已存在的相鄰模式

### CrunchLabs：內容驅動的完整作品盒

Build Box 每月提供一個可組裝玩具和配套影片。官方目前年繳方案約 US$27.45／盒、月繳年約方案約 US$29.95／盒。它賣的是 Mark Rober 的敘事、玩具設計、完成體驗和固定節奏，不是公開零件加價代購。

### AdaBox：電子生態系策展盒

AdaBox 以特定電子主題策展開發板、感測器與教學，過去約 US$60／季。Adafruit 現在規劃改成 Club AdaBox：收年度會員費取得限量硬體 drop 的優先購買權，盒子仍需另外購買。官方說明直接提到供應鏈、關稅和缺料使固定時程難以維持。

這表示「定期訂閱」不是必要條件。對尚未掌握需求量的小型團隊，先採預購或 drop 比承諾每月出盒安全。

## 建議商業模式：Project Drop

### 基本流程

1. 每週從社群蒐集候選專案。
2. 公開下一批 3 個候選，讓會員投票。
3. 團隊先做出可重現樣機，凍結 BOM 和韌體版本。
4. 公開零件成本、服務費、出貨日期和最低成團數。
5. 開放 14～21 天預購；達門檻才採購。
6. 到貨後抽測、分裝、預燒錄，再一次出貨。
7. 保留完整教學、故障排除和替換料清單。

### 收費公式

`售價＝實際 BOM＋包材／金流／履約成本＋固定套件服務費＋授權分潤＋運費`

服務費不是模糊加價，而是明列它涵蓋：

- 選型與版本核對。
- 相容性驗證。
- 小量採購和分裝。
- 預先燒錄或測試。
- 中文步驟卡、影片和除錯指南。
- 缺件與 DOA 更換保障。

建議不要只收 10% 手續費。小額套件的客服與分裝成本不會隨 BOM 等比例下降，應採「每盒固定服務費＋超過門檻後的小比例」。例如：

- BOM NT$600 以下：服務費 NT$350～450。
- BOM NT$600～1,500：服務費 NT$450～650。
- BOM NT$1,500 以上：固定 NT$500 加 BOM 的 10～15%。

## 三層產品

### 1. Starter Kit：最低可動版

只保證核心功能能跑，不附電池與完整外殼。適合已經有工具的 maker，價格最低。

### 2. Complete Kit：照片完成版

包含正確電池、線材、螺絲、外殼、燒錄完成的主板與完整教學。這會是主力商品，因為它真正消除阻力。

### 3. Classroom／Workshop Pack：團體版

5～20 組套件、備品包、教師投影片、90～180 分鐘課程腳本和講師版故障排除。B2B／教育工作坊通常比單盒零售更容易吸收服務成本。

## 更好的長期結構：共用核心＋專案擴充包

不要讓使用者每個月都買一塊新的 ESP32、電池與螢幕。可以建立一個標準核心：

- ESP32-S3。
- 螢幕、按鍵、聲音與電池。
- 防呆接頭。
- 瀏覽器燒錄器。

之後販售較便宜的感測器、機構、外殼和韌體主題包。這會形成：

- 第一次：核心套件 NT$1,500～2,500。
- 後續：專案包 NT$450～1,200。
- 每個月可以做不同作品，卻不重複購買昂貴電子核心。

這比純訂閱更符合「量產標準件負責功能，3D 列印負責造型差異」的方法，也降低電子廢棄物。

## 單盒損益範例

以單鍵掌機 Complete Kit、50 盒預購為例：

| 項目 | 每盒 |
| --- | ---: |
| 主板、螢幕、按鍵、電池與充電 | NT$620 |
| 外殼、螺絲、線材與耗損 | NT$180 |
| 包材與步驟卡 | NT$90 |
| 分裝、燒錄和抽測 | NT$120 |
| 金流、售後和瑕疵準備 | NT$140 |
| 創作者／內容分潤 | NT$100 |
| 完整履約成本 | **NT$1,250** |
| 建議售價 | **NT$1,790～1,990** |
| 每盒貢獻 | **NT$540～740** |

這約是售價 30～37% 的貢獻空間，但仍未扣除固定的人員、樣機、攝影、網站與倉儲成本。只在 BOM 上加 10% 幾乎不可能支撐退換貨和客服。

## 這批點子的商品化順序

1. **單鍵掌機**：零件少、成功判定清楚，最適合第一盒。
2. **ESP-NOW 雙人距離徽章**：兩個裝置天然適合送禮、朋友共同購買。
3. **圓形螢幕原創生態球**：視覺吸引力強，可作進階高單價 drop。
4. **NFC 教室銀行**：改做教師包和工作坊，而不是一般消費盒。
5. **Kindle 打字機**：不附 Kindle，只售相容型號明確的改造包；退貨風險較高。
6. **智慧溫室**：先做半成品工作坊，不宜當第一批郵寄套件；水路、植物和鋁框會放大客服成本。

## 創作者合作

不能只看到 Reel 就複製販售。可採以下方式：

- 原作者提供設計與內容，平台負責 BOM、在地採購、包裝和售後。
- 每盒支付固定授權費或售價 5～10% 分潤。
- 若為開源專案，逐一遵守軟硬體與 3D 模型授權；非商用授權不得放進付費套件。
- 平台保留相容性修改，並公開原作連結和改動內容。

長期可讓創作者提交專案，平台成為「電子作品的出版商」：創作者像作者，套件像書，平台負責編輯、印製、發行和讀者服務。

## 主要風險

- **庫存**：用預購門檻、替代料先驗證和批次 BOM 鎖版處理。
- **版本漂移**：每盒標示硬體 revision，教學依 revision 分流。
- **鋰電池運輸**：初期可提供不含電池版，或只做本地配送。
- **客服吃掉毛利**：設計可觀察的自檢流程、拍照診斷點與單件補寄。
- **焊接門檻**：Complete Kit 使用預焊接板、防呆接頭；焊接版另列為進階產品。
- **著作權與商標**：避免直接販售 Pokémon 等粉絲作品；先做原創題材。
- **每月交付壓力**：前 6～12 個月不承諾固定月訂閱，只做準備完成才發售的 drop。

## 最小商業驗證

1. 選單鍵掌機作第一盒。
2. 先完成 3 台相同樣機，交給三位沒看過專案的人依說明組裝。
3. 記錄每個卡點與客服問題，修到 90 分鐘內可完成。
4. 製作商品頁，明列 BOM 價值、服務費和不含項目。
5. 以 30～50 盒為成團門檻預售，不先壓大量庫存。
6. 第一批只在台灣出貨，避開電池跨境問題。
7. 觀察完成率、補件率、客服分鐘數與第二盒購買意願，再決定是否發展會員制。

## 核心指標

- 開箱後成功完成率。
- 首次通電成功率。
- 每盒平均客服時間。
- 缺件／壞件補寄率。
- 使用者完成作品所需時間。
- 第二盒購買率，而不只是訂閱續約率。
- 共用核心被重複使用的次數。

## 結論

這門生意不是低毛利的零件代購，而是「專案出版＋硬體履約」。最適合的起點是限量預購、透明成本、固定服務費和高完成率；等三到五盒都能穩定交付，再考慮會員或訂閱。
