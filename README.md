# 靈感城市與點子筆記

[進入靈感城市](https://ioksengtan.github.io/idea/ideas.html)

城市程式、點子 Markdown 與參考圖片集中於本儲存庫。每個點子是一位居民，住在以點子造型作為屋頂地標的公寓中。

更新快照：`node scripts/build-ideas.cjs . HEAD`。測試：安裝 Playwright 後執行 `node tests/city.test.cjs`（預設 Edge）。

GitHub Pages 從 main 根目錄發布。城市開啟時會同步同一儲存庫的最新筆記，無法連線時使用 data/ideas.js 快照。
