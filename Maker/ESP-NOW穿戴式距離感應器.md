# ESP-NOW 穿戴式距離感應器

記錄日期：2026-10-03

## 靈感來源

社群影片使用兩塊帶彩色小螢幕的 LILYGO T-QT 開發板，讓兩台 ESP32 以 ESP-NOW 互相傳送資料，再用無線訊號強度呈現彼此接近或遠離的狀態。裝置可掛在衣服、背包或識別證上，螢幕以顏色與圖形即時回饋。

## 運作原理

ESP-NOW 是 Espressif 定義的無連線 Wi-Fi 通訊協定。裝置不必先連上路由器，就能直接用 Wi-Fi action frame 互傳短資料，適合遙控器、感測器與低延遲裝置。

兩台裝置可定期互傳心跳封包：

1. A 傳送封包給 B。
2. B 從收到的封包讀取 RSSI（Received Signal Strength Indicator）。
3. B 回傳自己的狀態或確認封包，A 也取得另一方向的 RSSI。
4. 程式對最近數筆 RSSI 做平均或濾波。
5. 將訊號分成「靠近」、「中等」、「遠離」、「失聯」等區間，顯示不同顏色或動畫。

Espressif 官方說明指出，ESP-IDF 5.1 之後可從 `esp_now_recv_info_t` 內的 `rx_ctrl.rssi` 直接取得 ESP-NOW 封包 RSSI。舊版本的接收 callback 不含這項資訊，需要升級或使用 promiscuous mode 擷取同頻道封包。

官方資料：<https://docs.espressif.com/projects/esp-faq/en/latest/application-solution/esp-now.html>

## 重要限制：RSSI 不等於精準距離

RSSI 只能當作粗略的接近程度，不能可靠地換算成公分或公尺。數值會受以下因素明顯影響：

- 人體遮擋與裝置佩戴方向。
- 天線朝向與兩塊板子的高度。
- 牆壁、金屬、家具造成反射與多路徑干擾。
- 鄰近 Wi-Fi 設備與使用頻道。
- 不同板子的天線與射頻個體差異。
- 發射功率、封包速率與場地環境。

因此介面不應顯示虛假的精確距離，較適合用四段式狀態或趨勢箭頭。若產品真的需要 10～30 cm 等級的可靠測距，應考慮 UWB；若只需要數公尺內是否出現，可評估 BLE RSSI，但同樣需接受環境誤差。

## 軟體設計建議

### 濾波

使用移動平均、中位數或指數移動平均，避免單一封包讓畫面不停跳動。

### 遲滯區間

進入「靠近」和離開「靠近」使用不同門檻。例如低於 -55 dBm 才進入近距離，高於 -60 dBm 才退出，以減少臨界值反覆切換。

### 雙向資料

比較 A 收到 B 與 B 收到 A 的 RSSI，若兩側差異太大，可能是人體遮擋或天線方向問題，不應直接判定距離。

### 遺失封包

RSSI 很弱與完全收不到封包是不同狀態。應記錄最後收到封包的時間，超時才顯示離線。

### 現場校正

第一次使用時，可讓兩個裝置在 0.5、1、2、4 公尺等位置取樣，再依場地建立粗略門檻；不要把單一實驗室參數套用到所有環境。

## 可延伸的產品點子

### 社交距離徽章

活動參加者靠近時，兩人的徽章顯示相同顏色或完成配對動畫，引導陌生人互動。可設定只有停留數秒才觸發，避免路過誤判。

### 尋人遊戲

每位玩家拿一個裝置，只能根據顏色與訊號強弱尋找指定隊友，像數位版冷熱遊戲。

### 雙人默契裝置

兩個裝置平時顯示不同圖案，接近後組成完整圖像、愛心、角色或一句話。

### 展覽導覽

展品旁放置固定 ESP32 beacon；觀眾走近時，隨身螢幕切換成對應展品資訊。由於 RSSI 定位容易誤判，展品之間需保留足夠距離。

### 兒童防走失提示

親子裝置在訊號持續變弱或失聯時發出提醒。這只能作為輔助提示，不能取代成人看護、GPS 或正式安全設備，也不能把 RSSI 當成可靠的實際距離。

### 團隊協作遊戲

讓多個節點以 ESP-NOW 組成小型網路；玩家必須靠近特定隊友、維持隊形或護送目標才能累積分數。

## 最小可行版本

1. 準備兩塊同版本的 T-QT Pro。
2. 使用裝置 MAC 位址進行 ESP-NOW peer 配對。
3. 每 100～250 ms 互傳序號、時間戳與電量。
4. 從接收 callback 取得 RSSI，保存最近 10～20 筆。
5. 以中位數或指數移動平均產生穩定值。
6. 先只顯示四段顏色，不顯示距離數字。
7. 在正面、背面、人體遮擋、走動及不同房間情境測試。
8. 加入失聯超時、低電量和重新配對介面。

## 與既有點子的連結

- 可併入「可程式化電子活動識別證」，成為接近感應與現場配對功能。
- 可搭配 M5Stack 或其他 ESP32 裝置製作較容易接線的原型，再縮小到 T-QT 穿戴版本。
- 可用在桌上型縮景越野場，讓車輛靠近檢查點時觸發任務；但固定檢查點若要求可靠判定，紅外線、NFC 或 UWB 可能更合適。

## 一句話定位

用兩塊掌上 ESP32 螢幕透過 ESP-NOW 感知彼此訊號強弱，將「靠近某個人或物件」變成可見、可玩的穿戴互動。
